# 駄菓子屋ゲームセンター

子どもの頃、駄菓子屋の店先に置いてあったゲームをブラウザーで再現しています。
インストール不要・登録不要。PCでもスマホでも無料で遊べます。

### ▶ https://yhdog0425-eng.github.io

---

## このリポジトリの役割は2つ

### ① 各ゲームへの「短い直行URL」を配る

**これが主な役割です。**

YouTubeは説明欄のURLを約41文字で打ち切り、コピーしても途中までしか取れません。ゲーム本体のURL（50文字）ではこれに引っかかるため、ここに短い別名を置いて転送します。

| 短い直行URL | 文字数 | 転送先 |
|---|---|---|
| `https://yhdog0425-eng.github.io/invader` | 39 | [retro-invaders-84](https://yhdog0425-eng.github.io/retro-invaders-84/) |

**動画の説明欄に載せるのは、この短いURLのほうです。**

### ② 全作品を並べた入口ページ

`index.html` が一覧ページです。ただし**普段は宣伝しません**（下記の方針を参照）。

---

## 導線の方針

**YouTubeを各ゲームの入口にする。**

```
ゲームA の動画 ──→ ゲームA（直行）
ゲームB の動画 ──→ ゲームB（直行）
ゲームC の動画 ──→ ゲームC（直行）
```

各ゲームのページからは、サイト内の他のゲームへは行かせません。かわりに「ほかのゲームは YouTube で」としてチャンネルへ戻します。**サイト内でゲーム同士を行き来できると、他のゲームの紹介動画を見てもらえなくなるためです。**

1動画＝1ゲーム。ゲームを作ったら、その動画を1本作る、という流れです。

## 新しいゲームを追加するときの手順

1. ゲーム本体は別リポジトリで作り、GitHub Pages で公開する
2. **このリポジトリに短い直行URLを追加する**
   `invader/index.html` をコピーして、たとえば `block/index.html` を作り、
   中の転送先URL（3か所）を新しいゲームのURLに書き換える
   → `https://yhdog0425-eng.github.io/block`（37文字）ができます
3. 一覧ページにも載せる場合は、[index.html](index.html) の `GAMES` 配列に1つ追記する

```js
const GAMES = [
  {
    title: "作品名",
    year: 1980,
    desc: "短い紹介文",
    url: "https://yhdog0425-eng.github.io/リポジトリ名/",
    thumb: "https://yhdog0425-eng.github.io/リポジトリ名/ogp.png",
    ready: true,     // false にすると「準備中」の暗い筐体になります
  },
];
```

> 短い別名は **合計41文字以内**に収めてください。`https://yhdog0425-eng.github.io/` の時点で32文字使うので、**別名部分は9文字までが安全圏**です。

## OGP画像を作り直すには

```
powershell -ExecutionPolicy Bypass -File .\make-ogp.ps1
```

`ogp.png`（1200×630）が生成されます。LINEやSNSで共有したときのカード画像です。

> `make-ogp.ps1` は **UTF-8（BOM付き）** で保存してください。BOMがないと PowerShell 5.1 が日本語を文字化けさせ、構文エラーになります。

## 技術的なこと

- HTML1ファイル完結。ビルド不要、依存ライブラリなし、外部通信なし
- 走査線とビネットはCSSのみで再現（ゲーム本体のCanvas実装と見た目を揃えてあります）
- ドット絵はインラインSVG
